# OMNIwx Planning Snapshot

> Consolidated into [production-readiness-plan.md](production-readiness-plan.md).

The former Gantt mixed completed engineering, estimates, and acceptance gates.
That made dates look like commitments and let an implementation appear complete
before it had device or operational evidence. OMNIwx now uses gate-based
planning:

1. `current-status.md` records the verified present state.
2. `production-readiness-plan.md` records the dependency order and exit gates.
3. `full-release-path.md` records the release procedure.

Use a temporary project-management tool for calendar commitments. Update the
canonical plan when sequencing changes; do not recreate a second roadmap here.
